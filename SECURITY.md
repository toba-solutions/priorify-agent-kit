# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability, exposed
credential, authorization bypass, or privacy concern.

Email [support@toba.solutions](mailto:support@toba.solutions) with:

- a concise description of the issue;
- affected skill, package, client, or Priorify endpoint;
- reproduction steps or a minimal proof of concept;
- the potential impact; and
- a safe way to contact you.

Do not include live access tokens, customer data, or destructive payloads. We
will acknowledge a complete report as soon as practical and coordinate
validation, remediation, and disclosure with the reporter.

## Scope

This repository contains public instructions and connection metadata. Reports
about Priorify's hosted MCP authorization, workspace scoping, approval controls,
or accidental credential exposure are in scope even when the vulnerable code
is maintained outside this repository.

General support questions and requests for additional integrations are not
security reports; use [support@toba.solutions](mailto:support@toba.solutions).

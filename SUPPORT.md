# Support

## Using Priorify Agent Kit

Start with the installation and connection instructions in [README.md](README.md)
and the client notes in [docs/compatibility.md](docs/compatibility.md).

For account, OAuth, workspace-permission, billing, or private-data questions,
email [support@toba.solutions](mailto:support@toba.solutions). Do not post
screenshots or logs containing private product information in a public issue.

Use GitHub issues for public, reproducible problems with:

- skill discovery or invocation;
- package manifests and release archives;
- documented client compatibility; or
- unclear or incorrect public instructions.

Security concerns must follow [SECURITY.md](SECURITY.md).
